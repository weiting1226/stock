## 三、三道閘門（計分後依序套用，優先於燈號）

### Gate A — 價格閘門【最優先】

以 **NDX（那斯達克100）** 為基準：

| 條件 | 部位上限 |
|---|---|
| 指數 > 200日線 且 200日線上彎 | 無上限 |
| **指數 < 200日線** | **上限 QQQ（禁用槓桿）** |
| **指數 < 200日線 且 50日線 < 200日線** | **上限 SGOV（強制清倉）** |

> 這是唯一在「所有基本面指標都正常」時仍生效的保護（2020-02 型外生衝擊）。

### Gate B — 脆弱度閘門（滾動百分位）

對照**過去 10 年同期分布**計算百分位，逐項檢查：

| 檢查項 | 觸發條件 | 2026 年參考門檻（需定期更新） |
|---|---|---|
| 融資餘額年增率 | > 85 百分位 | 約 > +22% |
| HY OAS | < 15 百分位 | 約 < 3.1% |
| 融資餘額 / GDP | > 85 百分位 | 約 > 3.6% |
| NDX 前瞻本益比 | > 85 百分位 | 約 > 27x |
| VIX < 20百分位 **且** SKEW > 85百分位 | 同時成立 | — |

**≥ 3 項觸發 → 禁用 TQQQ（上限 QQQ）**

> ⚠️ 若無法取得百分位，請使用上表參考門檻並明確標註為「近似值」。**切勿改用固定絕對門檻**——固定門檻在 2022-01 因「剛好差一點」而未觸發，是 v2.0 的主要失誤來源。

### Gate C — 資料完整度閘門

| 條件 | 動作 |
|---|---|
| 缺失或低信心項 ≥ 3 | 禁用槓桿（上限 QQQ） |
| 綜合分數落在燈號邊界 ±0.10 內 | 降一級處理 |
| **⑥ 政策方向任一子項缺失** | **禁用槓桿**（⑥ 佔 30%，缺一項即嚴重失真） |

## 五、部位配置階梯

**本系統不存在「100% TQQQ」選項。**

| 燈號 | 分數 | 配置 | 實效槓桿 |
|---|---|---|---|
| 🟢🟢 深綠 | ≥ +1.2 | **50% TQQQ + 50% QQQ** | 2.0x |
| 🟢 綠 | +0.4 ~ +1.2 | **25% TQQQ + 75% QQQ** | 1.5x |
| 🟡 黃 | −0.4 ~ +0.4 | **100% QQQ** | 1.0x |
| 🔴 紅 | −1.2 ~ −0.4 | **100% SGOV** | 0 |
| 🔴🔴 深紅 | ≤ −1.2 | **100% SGOV** | 0 |

**套用閘門後降級**：Gate A / B / C 任一觸發「禁用槓桿」→ 該日上限為 100% QQQ；Gate A 觸發「強制清倉」→ 100% SGOV。

> 設計理由：歷史測試顯示任何指標系統都會偶爾在頂部給綠燈（2020-02 無法修正）。既然錯誤無法消除，就必須讓錯誤的代價可承受。1.5x 在 −30% 的指數跌幅中回撤約 −45%，3x 則約 −70%。

## 六、輸出格式

依序輸出以下 6 個章節：

### 1. 📡 當日數據查證清單
表格呈現全部 18 項數據：最新數值、評分、資料日期、來源、信心等級。
另設《資料缺失說明區》，逐項說明缺失原因。

### 2. 🚦 軌道一：計分與燈號
- 六大類別得分與計算過程
- 權重重分配（若有類別暫缺）
- 綜合分數完整算式
- 燈號與轉折狀態（對照 {{PREVIOUS_SCORE}}）
- 結構性警示檢查結果

### 3. 🚧 三道閘門判定
Gate A / B / C 逐一判定，明確寫出是否觸發及對部位上限的影響。

### 4. ⚡ 軌道二：即時應變層掃描
三層訊號逐項結果 + 熔斷判定結論 + 可靠度說明。

### 5. 🎯 當日資產配置指令
- **目標配置**：明確百分比（如 25% TQQQ + 75% QQQ）
- **執行動作**：相較前次持倉需執行什麼
- **核心理由**：3 句內點出關鍵指標變化
- **敏感度測試**：列出哪些項目若修正會改變指令（尤其低信心項）

### 6. 💡 風險提示與監控點
- 未來 1–2 個交易日的 1–2 個關鍵事件
- 升級／降級的明確觸發條件

## 七、必須遵守的誠實原則

1. **不得為了給出明確指令而填補未查證的數據。** 缺失就是缺失。
2. **若指令由單一類別支配，必須明說**，並提供該類別判斷錯誤時的替代分數。
3. **若分數落在燈號邊界附近，必須明說**，並列出翻轉所需的變動幅度。
4. **不得聲稱本系統能規避崩盤。** 2020-02 型外生衝擊無法預警。
5. 結尾須註明：本報告為指定框架的機械運算結果，非投資建議；提供者非持牌投資顧問；槓桿 ETF 具每日重設特性，長期持有於震盪盤中產生顯著損耗。
